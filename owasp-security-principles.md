# OWASP Security Principles

## About

This section documents my learning about important security principles that help organizations design and maintain secure systems.

## Minimize the Attack Surface

The attack surface is the number of possible ways an attacker can access or attack a system.

Organizations can reduce the attack surface by:

- Removing unnecessary software
- Disabling unnecessary services
- Limiting access
- Reducing unnecessary features

## Principle of Least Privilege

Users should only have the minimum access they need to perform their jobs.

This helps reduce damage if an account is compromised.

## Defense in Depth

Defense in depth means using multiple layers of security.

Examples include:

- Strong passwords
- Multi-factor authentication
- Firewalls
- Antivirus software
- Access controls

If one security layer fails, another layer may still provide protection.

## Separation of Duties

Important responsibilities should be divided between different people.

This can help reduce:

- Mistakes
- Fraud
- Abuse of access

## Keep Security Simple

Security systems should be easy to understand and manage.

Overly complicated security systems can lead to mistakes and configuration problems.

## Establish Secure Defaults

Systems should use secure settings by default.

Users should not have to manually configure basic security settings.

## Fail Securely

If a security system fails, it should choose the safest option.

For example, access should be denied rather than automatically allowed.

## Don't Trust Services Automatically

External services and third-party systems should not automatically be trusted.

Organizations should verify and monitor them.

## Avoid Security Through Obscurity

Security should not depend only on hiding information.

Strong security controls should still be used.
