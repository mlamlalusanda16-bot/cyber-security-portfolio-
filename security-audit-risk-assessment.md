# Security Audit and Risk Assessment

## About

This section documents my learning about security audits and risk assessments in cybersecurity.

## Security Audit

A security audit is a review of an organization's security.

It helps identify whether:

- Security controls are working
- Security policies are being followed
- There are security weaknesses
- The organization is managing risks properly

## Audit Scope and Goals

### Scope

The scope defines what will be checked during an audit.

This may include:

- People
- Systems
- Technology
- Security policies
- Procedures
- User access

### Goals

Goals explain what the organization wants to achieve from the audit.

Examples include:

- Improving security
- Identifying weaknesses
- Checking security controls
- Reducing risks

## Risk Assessment

A risk assessment helps identify possible security problems.

It involves identifying:

### Threats

Threats are possible dangers that could cause harm.

Example: A cybercriminal attempting to access a system.

### Vulnerabilities

Vulnerabilities are weaknesses that could be exploited.

Example: A weak password.

### Risk

Risk is the possibility that a threat could exploit a vulnerability and cause harm.

## Simple Example

- **Threat:** A hacker
- **Vulnerability:** A weak password
- **Risk:** Unauthorized access to an account
