Beginner Cybersecurity Risk Assessment Practice Project

---

# Scenario

A small company stores important information on computers and uses employee accounts to access company systems.

The company wants to identify possible cybersecurity risks and improve its security.

---

# Risk Assessment

| Asset | Threat | Vulnerability | Risk | Security Control |
|---|---|---|---|---|
| Employee accounts | Hacker | Weak passwords | Unauthorized access | Strong passwords and MFA |
| Company computers | Malware | Outdated software | System infection | Software updates and antivirus |
| Company data | Ransomware | No backups | Data loss | Regular backups |
| Email accounts | Phishing | Lack of awareness | Stolen credentials | Security awareness training |
| Company network | Unauthorized access | Weak access controls | Network compromise | Firewalls and access controls |

---

# Key Concepts

## Assets

Assets are valuable things that an organization needs to protect.

Examples include:

- Computers
- Company data
- Employee accounts
- Networks
- Servers

---

## Threats

Threats are possible dangers that could cause harm.

Examples include:

- Hackers
- Malware
- Phishing
- Ransomware
- Unauthorized users

---

## Vulnerabilities

Vulnerabilities are weaknesses that could be exploited.

Examples include:

- Weak passwords
- Outdated software
- Missing security updates
- Poor access controls
- Lack of employee awareness

---

## Risks

Risk is the possibility that a threat could exploit a vulnerability and cause harm.

For example:

A hacker may exploit a weak password and gain unauthorized access to an employee account.

---

# Recommended Security Controls

Based on this assessment, I recommend:

- Using strong passwords
- Enabling Multi-Factor Authentication (MFA)
- Keeping software updated
- Using antivirus or endpoint protection
- Creating regular backups
- Providing cybersecurity awareness training
- Using firewalls
- Limiting unnecessary user access

---

# Conclusion

This risk assessment identified several common cybersecurity risks.

Understanding the relationship between assets, threats, vulnerabilities, and risks can help organizations choose appropriate security controls.
